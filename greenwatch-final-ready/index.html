Frequently asked questions

Can this run entirely from GitHub Pages?

Yes. HTML, CSS and JavaScript are static; Google Apps Script provides the database endpoint.

Is Google Sheets suitable as the database?

For lightweight, non-sensitive records such as leads, consent flags, session status and plan metadata, yes.

Does it access WhatsApp accounts?

No. This build does not retrieve chats, OTPs, passwords, QR sessions, tokens or account secrets.

Can location be stored?

Only a location explicitly shared by an authorized user should be stored. The included API requires a consent flag.
